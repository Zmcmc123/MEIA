# Contributing to MEIA / 参与 MEIA

MEIA is source-available under the PolyForm Noncommercial License 1.0.0. It is
not currently accepting unsolicited code pull requests. This boundary avoids
unclear ownership and relicensing rights while contribution terms are being
prepared.

MEIA 依据 PolyForm Noncommercial License 1.0.0 公开源码。目前暂不接受未经邀请的
代码 Pull Request，以免在贡献条款尚未完成时产生版权归属和商业授权边界不清的问题。

## Issues are welcome / 欢迎提交 Issue

You may use the issue templates to report a reproducible bug or propose a
feature. / 可以使用仓库提供的 Issue 模板报告可复现问题或提出功能建议。

- Search existing issues first. / 先搜索是否已有相同问题。
- Include the MEIA version, operating system, Python version, input format, and
  exact reproduction steps. / 提供 MEIA 版本、操作系统、Python 版本、输入格式和
  完整复现步骤。
- Use the smallest structure that still reproduces the problem. / 尽量使用能够
  复现问题的最小构型。
- Do not upload confidential, proprietary, personally identifying, or
  export-controlled data. / 不要上传机密、专有、可识别个人身份或受出口管制的数据。
- Report vulnerabilities through [`SECURITY.md`](SECURITY.md), not a public
  issue. / 安全漏洞请按 [`SECURITY.md`](SECURITY.md) 私下报告，不要公开提交。

## Invited contributions / 受邀贡献

If the maintainer explicitly invites a code or documentation contribution,
wait for the written contribution terms before submitting it. The invitation
and applicable terms must be clear before a pull request is opened. A pull
request does not by itself grant MEIA commercial-use rights.

如维护者明确邀请代码或文档贡献，请先确认书面的贡献条款，再开始提交。邀请范围和适用
条款应在创建 Pull Request 前明确。提交 Pull Request 本身不会授予 MEIA 商业使用权。

For commercial licensing, follow [`license/COMMERCIAL.md`](license/COMMERCIAL.md).
商业授权请参阅 [`license/COMMERCIAL.md`](license/COMMERCIAL.md)。
