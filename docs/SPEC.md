# MEIA — 原子构型可视化需求规格与实现路径

> 文档版本：1.8
> 创建日期：2026-08-20
> 状态：v0.11.0 功能基线已实现；大体系优化分支待真实体系稳定性验收

---

## 1. 项目背景

### 1.1 现状

用户已有一个基于 ASE + Streamlit 的原子构型二维投影工具（`atom_visualize_app.py`），可将 POSCAR/CONTCAR 等结构文件导出为扁平化风格的二维投影图（SVG/PNG/PDF）。

该工具使用 ASE 的 `plot_atoms()` 函数，核心流程为：

1. 通过 `rotation` 字符串（如 `"10x,20y,30z"`）构建 3×3 旋转矩阵
2. 将原子 3D 坐标左乘旋转矩阵，取前两维 (X, Y) 作为 2D 屏幕坐标
3. 第三维 (Z) 用于深度排序（z-order）
4. 每个原子绘制为 `matplotlib.patches.Circle`，基于共价半径 × 缩放因子

### 1.2 核心缺陷

ASE 的 `plot_atoms()` **不绘制化学键**。用户当前的工作流程是：

1. 用 ASE 工具导出仅含原子的 SVG
2. 在 Adobe Illustrator 中手动逐根添加化学键
3. 遇到批量文件时无法处理

### 1.3 目标

开发程序自动生成带化学键的原子构型扁平化二维投影图，化学键风格与 Illustrator 手动编辑结果一致（参考 VESTA 棒状键风格），支持批量处理。

产品名称为 MEIA（Molecular and Extended-system Illustration Assistant）。
Python 包、导入路径和批处理入口统一为 `meia/`、`meia.*` 和 `python -m meia.batch`，
不提供旧命名兼容层。应用支持
`zh-CN` 与 `en` 完整界面切换，手动语言偏好优先于浏览器语言并持久保存；
语言状态不进入可视化状态、通用风格或工作状态快照。

## 2. 化学键风格规格

基于对用户提供的 Illustrator 导出 SVG（`未标题-2.svg`）的逐元素解析，化学键的精确结构如下。

### 2.1 单根化学键的组成

一根从原子 A 到原子 B 的化学键在 2D 投影中由 6 个图形元素组成：

```
原子A ← 椭圆A(原子A颜色) ← 矩形A(原子A颜色) | 矩形B(原子B颜色) → 椭圆B(原子B颜色) → 原子B
                         ↑ 键中点 ↑
```

| 层 | 元素 | 填充色 | 几何 | 位置 |
|----|------|--------|------|------|
| 1 | 椭圆帽 A | 原子 A 颜色 | 圆心=中心线与 A 显示球面的交点 | 键端平滑过渡 |
| 1 | 椭圆帽 B | 原子 B 颜色 | 圆心=中心线与 B 显示球面的交点 | 键端平滑过渡 |
| 2 | 矩形 A | 原子 A 颜色 | 从 A 球面交点到裁剪键段中点 | 键的前半段 |
| 2 | 矩形 B | 原子 B 颜色 | 从裁剪键段中点到 B 球面交点 | 键的后半段 |
| 3 | 平行描边线 1 | 统一描边颜色 | 沿整段裁剪键体一侧 | 完整边线 |
| 3 | 平行描边线 2 | 统一描边颜色 | 沿整段裁剪键体另一侧 | 完整边线 |

### 2.2 几何参数关系

从 SVG 测量得到的规律：

1. 两个显示球半径均使用当前半径方案解析出的最终显示半径；默认为“元素共价半径 × 全局倍率”。
2. 两矩形覆盖两个球面交点之间的外露键段，并在该键段中点等分着色。
3. 键宽由统一的 `bond_width_ratio` 控制，默认 0.45。
4. 椭圆帽宽度等于键宽，高度为键宽 × `ellipse_ry_ratio`；只随统一键宽缩放。
5. **椭圆旋转角度** = 键方向角度
6. **椭圆中心** = 三维中心连线与显示球面的交点。
7. 若两个显示球相交或相切，距离规则仍可匹配，但不生成球外可见键体。

### 2.3 描边

- 颜色：`#231815`（深灰近黑）
- 默认键描边线宽：0.25；所有化学键统一使用同一参数。
- 两个矩形不带边框；两个椭圆帽自带外轮廓；键体两侧由两条完整平行线描边。

### 2.4 渲染顺序（Z-order）

每根键作为一个不可拆分的深度排序对象，深度取裁剪后整段键的中点。六个对象共享该深度，并按“椭圆帽 → 矩形 → 两条平行线”的插入顺序绘制；因此矩形遮住椭圆内侧，只露出外侧弧线。整键与原子再按投影深度排序。该策略优先保证 SVG 单键编组和 Illustrator 可编辑性，不再对两个半键分别参与全局遮挡排序。

### 2.5 不区分键级

暂时不区分单键/双键/三键，所有键统一按上述棒状风格绘制。

### 2.6 配色

内置通用风格 JSON 完整列出 1–118 号元素颜色。以下五种元素保持既有主色调，
其余元素在同一柔和、低饱和风格中补齐：

| 元素 | 颜色 | 说明 |
|------|------|------|
| H  | #E6E6E5 | 浅灰 |
| C  | #3F4F6A | 深蓝灰 |
| O  | #E5A6A6 | 粉红 |
| Si | #5386C6 | 蓝 |
| Ca | #9ECC91 | 绿 |

旧调用仍可对缺失颜色回退到 Jmol；App 默认风格本身不依赖字段缺失回退。

## 3. 功能需求

### F1. 结构读取

- 通过 ASE 读取 POSCAR/CONTCAR、CIF、XYZ、LAMMPS data 等格式
- 保留 Streamlit 文件输入方式
- 读取失败时给出具体原因

### F2. 投影与视角

- 借鉴 ASE `PlottingVariables` 的投影逻辑（旋转矩阵、坐标变换、缩放、偏移），封装为独立模块
- 支持三轴旋转角度输入
- 支持视角预设（常见晶面方向）
- 3D 预览上方提供 VESTA 式视角工具：角度步长默认 `90°`，支持屏幕方向的上/下/左/右旋转，以及沿晶格直接基矢正方向观察的 `a (100)`、`b (010)`、`c (001)` 按钮
- 3D 工具按钮立即更新前端草稿相机，但不直接更新 2D；仍以“应用当前视角”作为唯一同步确认点
- 初次导入的默认视角为 `-90x`，确保 3D 水平观察和 2D 投影均保持笛卡尔 `+z` 朝屏幕上方
- **遮挡关系**：正确处理原子间、原子与化学键之间的遮挡关系（Z-order 排序）

### F3. 化学键识别

- 上传构型时，只为当前实际匹配到的元素对初始化规则；通常使用“共价半径和 × 成键容差”，H–O 额外使用 `1.20` 的元素对倍率以覆盖常见 O–H 键长。
- 对默认生成而非 JSON 显式保存的规则，先按上述距离上限搜索，仅保留实际匹配元素对；该对最短实际键长 `≤ 2.0 Å` 时“显示键”和“参与周期整理”均默认开启，`> 2.0 Å` 时两者均默认关闭；`2.0 Å` 是包含边界。JSON 中的显式规则不会被重分类。
- 每个元素对使用闭区间绝对距离 `[min, max]`，单位 Å；“显示键”仅控制共价键图层，“参与周期整理”仅控制构建 `PeriodicDisplay` 的拓扑边，二者可独立开关。
- 化学键表格、逐元素对控件和原子选择中的成键选项只显示当前构型实际匹配数大于 0 的元素对，不提供排列组合式新增/删除入口。
- 通用风格中未匹配的元素对规则继续保留但不显示；提交表单只更新当前可见规则，保证跨构型风格可移植性。
- 具体原子可针对相关元素对设置“继承、强制显示、强制隐藏”；强制隐藏优先于强制显示，例外不能绕过距离范围。
- 同一根键两端的强制例外冲突时，界面必须列出原子序号与键 ID，并明示“强制隐藏优先”。
- 保留非零晶胞偏移的周期镜像键，包括单原子与自身周期镜像的成键；反向候选只保留一次。
- 化学键控件位于一个缓冲表单中，只有点击“应用化学键设置”后才原子化替换已应用状态，并同时更新 3D、2D 和导出。
- 周期整理出现歧义时，页面必须给出结构化警告：诊断数、涉及原子数、相关元素对和“化学键”模块的调整路径；冲突部分保守保持原位，不猜测物理分组。
- 225 原子参考案例的默认状态无周期冲突警告；只有显式开启 Ca–O 的“参与周期整理”后，才出现实际警告：“周期整理检测到 2 项冲突，涉及 163 个原子；相关元素对包括 Ca–O、O–Si。请在‘化学键’模块调整这些元素对的‘参与周期整理’设置。冲突部分已保守保持原位。”诊断数、原子数和元素对由当前结构/设置动态生成。
- 暂不区分单键/双键/三键

### F4. 化学键渲染

- 棒状键风格：双矩形（双色）+ 椭圆过渡帽 + 描边
- 先在三维空间用统一解析的最终显示半径构造两个显示球，中心连线与球面的交点作为键体端点，再投影到二维
- 两种颜色各占两个球面交点之间键段的一半；椭圆帽中心位于对应球面交点
- 椭圆帽与键宽保持固定比例，只随键宽整体缩放，不再随端点原子半径分别缩放
- 参数化：键宽、椭圆大小比例、描边颜色和粗细
- 每根完整键以裁剪键段中点参与全局深度排序，六个子对象保持固定内部顺序
- 周期镜像键由统一 `PeriodicDisplay` 实例化；仅当两个端点显示像都位于请求的 a/b/c 左闭右开范围内时渲染，并保留两个端点的实际 `image_shift`。

### F4.1. O–H···O 氢键

- 供体 O–H 必须来自当前已匹配的共价键结果；全局/逐键显示状态不改变氢键的几何候选集合。
- 氢键有三个独立已应用设置：“显示 O–H···O 氢键”、`H···O` 最大距离和 `∠O–H···O` 最小夹角；默认分别为开启、`2.5 Å`、`120°`，在同一化学键表单提交后同步驱动 3D、2D 和导出。
- 受体限定为另一个 O，默认使用 `H···O ≤ 2.5 Å` 与 `∠O–H···O ≥ 120°`，两个阈值均为包含边界。
- 不使用 O···O 距离判据；同一源受体的不同物理周期像是不同候选，2.5 Å 为严格闭区间上限。
- 3D、2D 与 SVG/PNG/PDF 导出共用同一组周期氢键实例，从 H 表面到受体 O 表面绘制虚线。参与的三个原子中，任一 `hide` 优先于任一 `show`，否则继承默认显示；最终色彩强度取三个参与原子的最小值。

### F5. 原子渲染

- 内置通用风格 JSON 包含 1–118 号元素的完整配色；侧栏按当前结构中的元素批量调整元素颜色
- 原子尺寸支持两套相互独立的档案：默认“共价半径”档案为全局倍率 `0.6`、键宽 `0.45`；“相等半径”档案为全局倍率 `1.0`、统一基础半径 `0.35 Å`、键宽 `0.45`。两套档案各自保存全局倍率、元素覆盖和键宽。
- 半径方案下拉框只编辑草稿；点击“应用原子设置”后，目标档案的原子半径与化学键粗细原子化同时生效。切换方案前的另一套档案保持不变。
- 界面的 `X 最终显示半径 / Å` 接收绝对值；提交时按新全局倍率反算参考覆盖。同次同时改倍率和元素绝对值时，元素绝对值优先；只改倍率不会新增元素覆盖。
- 侧栏半径控件的常用范围为：全局倍率 `0.1–1.5`、基础参考半径 `0.1–5.0 Å`、最终显示半径 `0.01–5.00 Å`。如合法 v7 状态的已应用值位于常用范围外，对应控件边界仅扩展到足以包含该值，避免页面中断或隐式改写导入状态。
- 半径只影响 2D/3D/导出的原子球与共价键/氢键表面裁剪，不进入共价键匹配、氢键候选或 PBC 拓扑识别。
- 保留轮廓粗细参数。
- 保留透明背景选项
- “原子选择”模块统一单选与多选，可按可搜索多选、一基序号范围、元素、反选，以及 3D 视口点击/屏幕矩形框选建立选区
- 对当前选区可独立启用具体原子颜色、绝对色彩强度和相关元素对化学键显示例外；未启用的操作不改变既有记录
- 3D 批量选择必须显式开启“选择模式”；点击与拖框只更新浏览器内临时选区，不触发 Streamlit 重跑，点击“确认选择”后才提交规范化的完整索引集合并一次刷新侧栏
- 选择模式下滚轮缩放仍可用；固定像素的 SVG 圆形选择框不得出现，临时选区由与原子等大的 Plotly 3D 高亮层表示。
- 正交视野缩放以 `scene.aspectratio` 的三个方向统一倍率为状态；原子直径、共价键线宽和氢键线宽按同一倍率实时更新，并设安全上下限。相机 `eye` 距离不作为正交缩放量。
- 3D 普通原子使用 0.95 不透明度和 1 px 纯黑轮廓；选中原子继续使用独立黄色高亮和选择轮廓。
- 3D 共价键按每个元素半键分别绘制轮廓：底线总宽比彩色主体多 1 px，形成两侧各 0.5 px 的轮廓；轮廓 RGB 为对应半键原色的 55%，透明度为 0.72。氢键以及 2D 与文件导出的六对象描边契约不受影响。
- 色彩强度始终从元素原色向白色混合，不在上次结果上累积；同时影响原子填充/描边和其对应的半键填充
- 整根键的描边色使用两端原子中较低的色彩强度
- 具体原子隐藏/恢复按源原子身份保存并作用于全部周期副本；周期副本共享源原子的选择身份，点击任一副本后高亮全部副本。
- 当全部源原子隐藏时，3D 与 2D 仍可构造，页面提示“当前没有可见原子”；原子、共价键与氢键图层为空，但启用的主晶胞框与 SVG/PNG/PDF 导出继续有效。
- `一键还原初始配置` 位于侧栏最底部，只恢复原子、化学键、晶胞与周期性、原子选择模块；保留当前相机/视角、导出设置、活动结构和快照会话。
- 还原基准为当前会话最近一次成功应用的通用风格；若从未成功应用，则使用内置默认风格。仅上传未应用、无效风格和工作状态快照均不更新基准。
- 还原同时清除上述模块尚未提交的控件草稿；原子选择表单在还原后换用新的控件身份，避免浏览器把已作废的序号、隐藏或化学键操作重新写回。

### F5.1. 大体系交互与预览

- 页面显示源原子数、实际周期显示实例数和 2D artist 估算值。复杂度使用隐藏原子过滤后的完整显示实例计算。
- 2D artist 估算值达到 5,000 后，页面不在每次 Streamlit 重跑时自动渲染 Matplotlib；用户通过“生成/更新 2D 预览”显式生成完整结果。
- 预览缓存同时绑定结构、可视化状态和已应用 2D 视角。状态变化后旧图可标记为过期供对照，但不能以当前文件名下载。批处理和最终 SVG/PNG/PDF 导出不使用该按需策略。
- 源原子数从 1,000 起，侧栏原子选择使用 200 项分页窗口；当前选区摘要最多显示 20 个身份，不向 Streamlit 传送全部选项。
- 运行时以默认强度和少量逐原子例外紧凑表示色彩强度；严格 schema v7 导出时仍展开为原有逐原子语义。
- 3D 缩放每帧仅使用一次批量 Plotly 数据/布局更新，并在约 80 ms 空闲后做最终同步；选择高亮只保留已选源原子的周期实例，屏幕点选/框选使用 36 px 网格索引。
- 显示原子实例从 20,000 起，旋转或缩放期间仅临时隐藏化学键描边和氢键，约 120 ms 无交互后恢复。该状态不进入 JSON，不改变图层开关或导出。
- 周期显示不得超过 50,000 个原子实例；超限时拒绝设置并给出明确诊断，不隐式降采样。
- 结构成键、周期展开和氢键几何候选作为会话内单条 `RenderTopology` 缓存；仅颜色、强度、原子半径、键宽、相机或导出参数变化时复用，拓扑键不匹配时拒绝过期复用。

### F6. 导出

- SVG（矢量，优先）— 可直接导入 Illustrator 后续编辑
- SVG 中每根键为一个真实 `<g>`，包含且仅包含 2 个椭圆帽、2 个矩形和 2 条完整平行线，并带原子索引、元素对和周期偏移元数据
- PNG、PDF
- 保持高 DPI 输出能力
- 页面 2D 预览固定显示为 `900×675` CSS px，内部使用 `1800×1350` PNG（2× 像素密度）；文件导出的 DPI 继续由导出设置独立控制
- 文件式导出默认拒绝覆盖已有路径，只能由调用方显式授权覆盖
- 页面图像、通用风格预设和工作状态快照的下载全部位于侧栏“导出”模块，主页面不再重复显示导出区。
- `examples/CONTCAR`、`examples/meia-visual-state.workspace.meia.json`、`examples/CONTCAR_meia.svg`、`examples/CONTCAR_meia-2.svg` 和 `examples/CONTCAR_meia-2.png` 构成当前公开教程案例。工作状态快照使用严格 schema v7；示例不代表经过验证的物理参数。大体系性能负载由 `python -m meia.benchmark_large_system` 在本地生成，仓库不附带大体积案例文件。

### F7. 批量处理

- 支持指定目录，批量读取构型文件
- 支持 `--preset` 复用严格 schema v7 通用风格预设；预设存在时覆盖零散 CLI 渲染参数；工作状态快照因绑定单一结构而明确拒绝。旧版本及未知未来版本不迁移、不接受。
- `--radius-scale` 与 `--bond-width` 只覆盖当前活动尺寸档案，不改变另一套档案、活动模式、统一基础半径或元素覆盖。
- 渲染前预检所有目标路径；不同格式的同主名输入不得静默映射到同一输出
- 默认保护已有文件；仅显式 `--overwrite` 允许批量更新
- 独立 Python 脚本，不依赖 Streamlit

## 5. 交互方案

### 5.1 框架

### 5.2 界面布局

└─────────────────────────────────────────────┘

### 5.3 工作流程

1. 加载文件 → Plotly 3D 中显示原子+键的 3D 模型
2. 用户在 3D 视图中拖拽，或使用角度步长、四向旋转与 a/b/c 晶轴按钮调整视角；这些明确操作会立即更新 3D，但仍只修改组件内的草稿相机
3. 用户点击“应用当前视角”；该按钮只提交相机方向并刷新 2D，不读取、不应用也不重置任何侧栏表单
4. 侧栏不再提供重复的视角模块；3D 工具栏的四向与 a/b/c 按钮遵循上述显式应用流程；缩放和平移仅保留在 3D，不改变 2D 投影方向
5. 开启 3D“选择模式”，连续点击原子或拖出屏幕矩形临时选区；这些前端操作不触发 Streamlit 重跑，只有“确认选择”会一次提交完整选区并同步“原子选择”表单
6. 在“原子选择”表单中对同一选区设置具体颜色、绝对色彩强度或具体原子化学键例外；点击“应用原子操作”后同步刷新 3D、2D 与导出
7. 侧栏折叠区固定按 `📁 文件 → 原子 → 化学键 → 晶胞与周期性 → 原子选择 → 导出` 排列，还原按钮固定在导出之后；通用风格和工作状态快照的全部导入操作归入文件模块，未载入结构时不显示原子选择模块、还原按钮禁用，且仅文件模块默认展开。
8. 每个侧栏模块只在自己的“应用”按钮提交时替换已应用状态
9. 导出图像、跨结构通用风格预设，或含结构坐标与具体原子状态的工作状态快照

3D 标题下固定显示：“拖拽调整视角；开启“选择模式”后可连续点击或拖框，点击“确认选择”才一次同步到侧栏，选择模式下滚轮仍可缩放。应用当前视角把 3D 相机传给 2D。”不追加动态氢键文案。

> Streamlit 1.38 的 `st.plotly_chart` 本身不返回相机 relayout；项目使用本地 Streamlit Components v1 组件桥接 Plotly 相机事件。只有用户主动点击按钮才提交，不因拖动连续触发整页 rerun。

### 5.4 视角预设

- 常见晶面：(001)、(110)、(111) 等
- 3D 工具栏沿晶轴：a、b、c 分别沿当前晶胞的直接基矢正方向观察；无晶胞或对应基矢为零时保守回退到笛卡尔 x、y、z 轴
- 用户保存的自定义视角

## 10. 决策记录

1. **不局限于 ASE**：可借鉴 ASE 投影代码并修改，也可采用其他方案。核心目标是投影正确、风格一致、可批量。
2. **不区分键级**：所有键统一棒状风格，暂不实现单/双/三键区分。
3. **六对象键组**：每根键固定为两个帽、两个矩形和两条完整平行线；SVG 后处理把它们合并为一个真实 `<g>`。
4. **双色键**：键从中间切分，两段分别取两端原子颜色。
5. **三维球面端点与椭圆过渡**：键体端点先由三维中心线与两个显示球面的交点确定；椭圆帽中心位于交点，并与键宽保持固定比例。
6. **Streamlit + Plotly 3D**：保留 Streamlit 框架，增加 Plotly 3D 交互预览作为"取景器"。
7. **引擎与 UI 解耦**：渲染引擎为纯 Python 函数，批量脚本可直接调用。
8. **显式应用视角**：3D 拖动只修改前端草稿；用户点击“应用当前视角”后才更新 Python session state 和 2D 输出。
9. **只同步方向**：2D 输出使用相机 `eye` 与 `up` 构建右手正交旋转矩阵；正交相机的缩放和 `center` 平移不改变 2D 构型方向。
10. **本地前端资产**：组件固定使用打包在 `dist/` 中的 Plotly.js 2.35.2，不依赖 CDN；`node_modules/` 仅用于本地重新构建。
11. **重叠显示球**：若两球相交或相切，球体外不存在正长度键段，因此不绘制该键；成键识别结果本身不受影响。
12. **整键排序**：一根键以裁剪段中点作为单个深度对象参与排序；这是 SVG 真编组的必要约束，接受不再按半键分别遮挡的取舍。
13. **规则优先级**：距离范围是硬边界；范围内按“任一端强制隐藏 > 任一端强制显示 > 元素对开关 > 全局开关”解析。
14. **严格 v7 双 JSON 边界**：通用风格只含视角、完整元素配色、顶层双尺寸档案、化学键（含元素对双开关、描边与氢键阈值）、晶胞与周期性和导出参数；不含结构或原子索引。`atoms` 不重复保存半径，`bonds.style` 不重复保存键体宽度。工作状态快照额外含元素序列、笛卡尔坐标、晶胞、PBC、当前选区、隐藏原子及全部具体原子设置。只接受 schema v7；快照导入确认与当前 payload 哈希绑定，更换文件即清除确认，且只替换内存结构，不写磁盘源文件。
15. **VESTA 式 3D 工具仍走确认边界**：角度步长与四向/a/b/c 按钮立即改变 3D 草稿视角，但不绕过“应用当前视角”；其中 a/b/c 使用晶格直接基矢，不按笛卡尔轴假定非正交晶胞。
16. **预览与导出分离**：页面 2D 预览固定为 900×675 CSS px，并嵌入 1800×1350 PNG 保留 2× 像素密度；PNG/PDF/SVG 文件导出继续使用独立导出参数。
17. **周期显示公式与唯一身份**：基础展开偏移为 `s_i`、请求副本为 `T` 时，`position(i,T) = original_position(i) + (s_i + T) @ cell`；源键 `i→j` 的偏移为 `O` 时，另一端请求副本满足 `U = T + s_i + O - s_j`。3D、2D、SVG 与选择组件都保留源索引和实际 `image_shift`。
18. **3D 批量选择走前端确认边界**：选择模式使用当前相机矩阵把原子中心投影到屏幕；点击切换最近原子，拖框加入框内原子。临时高亮只存在于组件前端，“确认选择”才发送一次 `select_atoms` 完整集合并触发 Streamlit 重跑。
19. **模块独立应用**：3D“应用当前视角”只提交相机；侧栏每个表单独立缓冲和提交，任一模块不得顺带提交另一个模块的未应用控件。
20. **正交缩放使用场景比例**：Plotly 正交视图通过统一调整 `scene.aspectratio` 改变构型的屏幕跨度；普通模式沿用 Plotly 原生滚轮，选择模式处理同类 `wheel` 事件并更新同一状态。原子和键样式更新必须原子化保留当前场景比例。
21. **3D 原子与键轮廓契约**：普通原子固定为 0.95 不透明度和 1 px 纯黑轮廓；选择高亮保留。3D 共价键以宽于彩色主体 1 px 的同元素深色半透明底线形成每侧 0.5 px 轮廓，并与主体同步缩放；轮廓 RGB 为半键原色的 55%，透明度为 0.72。氢键及 2D/SVG/PDF 的描边继续由既有渲染器负责。
22. **侧栏使用结构匹配投影**：JSON 导入归入文件折叠区；化学键表格、逐对控件及原子选择只消费当前构型实际匹配的元素对，未匹配的可移植规则保留在状态中但不显示。新增元素对入口只提供当前构型元素，并以默认距离建立新规则。
23. **有限基团与保守歧义**：基础显示像只由 `BondResolution.matched` 决定。有限成键分支跨边界时整体展开；对含不可唯一解释周期附着的二连通块，记录 `ambiguous_periodic_attachment` 诊断并保守保持零基础偏移，避免依赖元素或原子编号的猜测。
24. **周期范围与晶胞框**：a/b/c 使用左闭右开的整数范围，非 PBC 轴强制 `0 → 1`；预计原子实例超过 50,000 时原子化拒绝设置。多倍周期显示仍只绘制原始 `0–1 × 0–1 × 0–1` 主晶胞的一套框线。
25. **源级可见性与选择**：隐藏/恢复和具体原子样式绑定源索引并聚合到全部副本；隐藏只在周期拓扑构建后过滤，不反向改变基础显示像。全隐藏仍保留有限画布、可选主晶胞与有效文件导出。
26. **元素对双开关**：`enabled` 只决定共价键是否可见，`participates_in_periodic_unwrap` 只决定匹配键是否作为周期整理拓扑边。关闭 Ca–O 显示不得移动原子或改变 Si–O；单独开启 Ca–O 显示可显示键而不引入周期拓扑。
27. **可操作的周期冲突警告**：诊断统计必须从实际参与周期整理的匹配键归一化元素对，避免把纯显示键误报为拓扑冲突；界面定位到相关元素对的周期整理开关。
28. **单一渲染上下文**：元素对双开关、氢键设置、原子选择/颜色/强度共同构建一个 `RenderContext`，3D、2D、SVG/PNG/PDF、通用风格和工作状态不允许各自重新推导。
29. **MEIA 断代命名**：应用版本为 `0.11.0`；严格 schema v7 只使用 `meia_version` 与 `.meia.json`。Python 包、导入路径、模块入口、产品、会话、前端、SVG/Plotly/Matplotlib 元数据和当前文件名统一使用 `MEIA/meia`，不保留当前树例外。
30. **语言状态独立**：首次语言按浏览器判断，无法识别时回退中文；手动选择保存到 `meia.locale` 并优先。语言切换只替换词条，不重建结构、相机、3D 场景比例、选择草稿、可视化设置或导出设置，也不改变任一 JSON 字节。
31. **英文成键术语**：普通距离匹配连接统一称为 `Detected Bonds` / `Show Detected Bonds`，不把可能包含离子键或金属键的连接统称为 covalent bonds。
